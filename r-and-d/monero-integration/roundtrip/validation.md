# Validation map

This map records the original baseline. The subsequent
[watcher/guard validation matrix](watcher-authority.md#recovery-return-admission-and-validation)
and [qualification record](evidence/watcher-authority-qualification.json) cover
the newly composed watcher, credit and return-authority boundaries.

This map separates the linked node execution from component experiments and focused independent rechecks. Test sets overlap; their counts must not be added into a single bridge-security score. The [structured results](evidence/validation-results.json) retain case names, outcomes and original report digests. The [technical report](technical-report.md) states the authority and deployment limits.

The original native checkpoint passed **52/52**. The registered lifecycle author suite passed **20/20**; independent correction checks passed **2/2** reproductions and **12/12** affected cases, with eight unchanged cases deliberately skipped in that focused rerun. The corrected preapproval fault campaign passed **3/3** with two original round-5 responses witnessed in every case. Its unchanged post-share interruption case is retained as separate prior evidence. Cryptographic proof checks cover five outcomes; currentness helpers were independently exercised in fourteen isolated schedules.

Separate agent reviews inspected the implemented native, certificate, journal, source-evidence, Ergo join and lifecycle boundaries. They identified concrete issues and independently rechecked their corrections against file hashes. This is development review, not an external security audit or endorsement by Rosen/Monero maintainers.

The implementation status is **focused green for the local composed path**; target-runtime status is **verified on the stated local nodes**. No repository-wide TypeScript build, remote CI result, independently reproduced binaries, production watcher consensus, full concurrency/reorganization campaign or future-protocol migration is claimed. The source is provided for technical review and further integration.
